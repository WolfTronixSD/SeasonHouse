# SD card sounds

Folder `/mp3` on a FAT32 micro-SD card. Free sources: freesound.org, pixabay.com/sound-effects.

| File | Used for |
|---|---|
| 0001.mp3 | Angry hiss |
| 0002.mp3 | Scream / horror sting |
| 0003.mp3 | Evil laugh |
| 0004.mp3 | Creaky rope |
| 0005.mp3 | Heartbeat (10-15 s) |
| 0006.mp3 | Cartoon BOING |
| 0007.mp3 | Spider Disco music (30-45 s) |
| 0008.mp3 | Squeaky "Hiii!" |

Tip: normalise everything to the same loudness, and put 0.1 s of silence at the start of each file so the DFPlayer does not clip the first syllable.
