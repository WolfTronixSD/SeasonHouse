# Sound credits

Every file in `01/` to `05/` and in `simulator/sounds/sim/` is built by
`tools/soundpack/build.py` from the sources below, then mixed, pitched,
reverbed and levelled. Music melodies are public-domain tunes (J. S. Bach,
Toccata and Fugue in D minor; J. Pierpont, Jingle Bells) or written for this
project.

## Recordings: Sonic Pi sample library (CC0 1.0, public domain)

From <https://github.com/sonic-pi-net/sonic-pi/tree/main/etc/samples>, originally from freesound.org and placed in the public domain:
`ambi_dark_woosh`, `ambi_haunted_hum`, `bd_haus`, `drum_cymbal_closed`, `drum_heavy_kick`, `drum_tom_lo_hard`, `drum_tom_lo_soft`, `elec_tick`, `hat_cab`, `misc_cineboom`, `misc_crow`, `perc_door`, `perc_impact1`, `perc_snap`, `perc_snap2`, `sn_dolf`.
No attribution needed; listed as thanks.

## Voices: Kokoro TTS (Apache 2.0)

Spoken with the Kokoro-82M model (<https://huggingface.co/hexgrad/Kokoro-82M>, Apache License 2.0) through `kokoro-onnx` (<https://github.com/thewh1teagle/kokoro-onnx>, MIT). Voices used: `af_bella`, `af_heart`, `af_jessica`, `af_nicole`, `af_sky`, `am_adam`, `am_fenrir`, `am_michael`, `am_onyx`, `am_puck`, `am_santa`, `bm_george`.

## Synthesised in the build script

Plucked strings, bells, organ, bass, sleigh bells, wind, boings, creaks, the honk, crunches, squirrel chatter, ice crackle and the heartbeat timing.
